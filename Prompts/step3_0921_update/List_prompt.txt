# ✅ **Number Context Identifier (Thai Audio Transcript)**
## 🎯 **Your Job**
Identify and document **contexts where sensitive numbers are mentioned** in the Thai audio transcript below.
**Focus exclusively on segments containing actual digits (Thai number words or Arabic digits).**
**Skip segments without any numbers - only analyze segments with sensitive numerical information.**

---

## 🔥 **THE MOST IMPORTANT RULE: Context Completeness & Digit Presence**
The `"context"` field **MUST** contain **a complete description** of what the number represents and the situation around it.
**EVERY output segment MUST contain at least one digit (Thai number word or Arabic digit).**
**If you break this rule, your entire output fails.**

| ✅ **GOOD CONTEXT** | ❌ **POOR CONTEXT** |
|-------------------|-------------------|
| `"Customer providing their 16-digit card number for verification"` | `"Number sequence"` |
| `"Agent asking for the last 4 digits of customer's ID card"` | `"ID number"` |
| `"Customer stating their postal code for address verification"` | `"Postal code"` |
| `"Agent providing customer service phone number"` | `"Phone number"` |

> 🚨 **CRITICAL**: If the `"context"` field is **vague or incomplete** OR the segment **contains no digits**, **DISCARD THE ENTRY**.

---

## 📋 **Your 6-Step Process (Follow Every Time)**
1. **🔍 SCAN:** Read through the transcript. Identify **only segments containing actual digits**:
- Look for Thai number words (หนึ่ง, สอง, etc.) and Arabic digits (0, 1, 2, etc.)
- **Completely skip segments without any numbers**

2. **🔗 GROUP:** For each segment with numbers:
- Include the number mentioned and surrounding context
- Include words that explain what the number represents
- The segment ENDS when:
- The topic completely changes
- A different number is introduced for a different purpose
- A speaker change occurs with a new topic

3. **📝 DESCRIBE CONTEXT:** For each number segment, write a clear description:
- Who is mentioning the number (Agent or Customer)
- What the number represents (card number, ID, postal code, etc.)
- Why the number is being mentioned (verification, providing information, etc.)
- Be specific and complete in your description

4. **⏱️ SET TIMESTAMPS:**
- Use the **segment timestamps** `[100.0 --> 110.0]` from the transcript
- `start` = start time of the segment where the number is mentioned
- `end` = end time of the segment where the number is mentioned

5. **🏷️ ASSIGN TAGS:** Check the context and add **all** that apply:
- `"CARD-RELATED"`: Context involves credit/debit/member cards
- `"EXPIRY-DATE"`: Expiry date for credit/debit/member cards
- `"NATIONAL-ID"`: Context involves National identification, Citizen ID, "บัตรบาลชน"
- `"CONTACT-INFORMATION"`: Context involves phone numbers, addresses
- `"FINANCIAL"`: Context involves amounts, prices, payments, but not card details (should already assigned "CARD-RELATED").
- `"OTHER"`: None of the above

6. **✅ VALIDATE:** Check your context description against the Final Checklist below.

## ✅ **Final Checklist (MUST PASS ALL)**
Before you output an entry, **check every box**. If any box is unchecked, **DISCARD THE ENTRY**.
- [x] **Contains Numbers:** Segment MUST include actual digits (Thai number words or Arabic digits)
- [x] **Completeness:** `"context"` fully explains what the number represents and why it's mentioned
- [x] **Relevance:** The context is actually about the numbers mentioned, not just general conversation
- [x] **Accuracy:** The context description correctly interprets the situation in the transcript
- [x] **Speaker Identification:** Correctly identifies who is mentioning the number
- [x] **Appropriate Tags:** Tags accurately reflect the type of context
- [x] **Timestamp Accuracy:** Timestamps correctly cover the segment where the number context appears
- [x] **No Duplicates:** Not repeating the same context with slightly different wording
- [x] **No Hallucination:** The context actually exists in the transcript

## 📥 **Output Format (STRICT: JSON Lines)**
Output **one JSON object per line**.
Each object must have these keys:
- `"id"`: integer starting at 1
- `"start"`: float, start time from the segment
- `"end"`: float, end time from the segment
- `"context"`: string, complete description of what the number represents and the situation
- `"speaker"`: `"Caller"` or `"Agent"`
- `"tags"`: list of one or more from:
- `"CARD-RELATED"` → context involves credit/debit/member cards
- `"EXPIRY-DATE"` →  Expiry date for credit/debit/member cards
- `"NATIONAL-ID"` → context involves National identification, Citizen ID, "บัตรบาลชน"
- `"CONTACT-INFORMATION"` → context involves phone numbers, addresses
- `"FINANCIAL"` → context involves amounts, prices, payments
- `"OTHER"` → all others.

> ✅ **Example:**
> `{"id":1,"start":89.92,"end":94.70,"context":"Customer providing their card number digits (5,7,1,2,1,3,9) for verification","speaker":"Caller","tags":["CARD-RELATED"]}`

**No explanations, no text before or after. STOP after the last sequence.**
